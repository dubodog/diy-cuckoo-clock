# DIY 双门布谷鸟时钟

面向亲子制作的 Arduino UNO 布谷鸟钟：双门同时打开 → 鸟出来 → 按小时播放真实“布谷” → 鸟收回 → 双门同时关闭。

**当前阶段：固件可以编译、主机逻辑测试通过；实物仅安装好下方石英钟。完整安装教学正在返工，尚未完成实物联调。** 本仓库不是已经验证可照做的完整套件教程。

## 已确定的功能

- 三只 SG90：左门、右门、鸟各一只；程序同步设置两门目标。
- 08:00—20:00 整点报时，按十二小时制计数；13点一次、20点八次。
- 21:00—次日08:00不启动自动报时；08点恢复。夜间 `T` 测试也不响。
- 下方 AA 电池石英钟独立走时，用背面旋钮调节；报时时间通过电脑另设。
- DS3231 当前没有备用电池；断电后检查时间，必要时重新校时。
- 不要求3D打印。100元曾是目标，现有采购未证明能按齐套总价控制在100元内。

## 开发验证

```sh
python3 tools/test_firmware.py
```

需要 Python 3 和 C++ 编译器。此测试在电脑上使用模拟器件，不需要连接 UNO。
Arduino CLI 编译、依赖安装和首次运行见 [固件说明](firmware/README.md)。默认舵机角度是设计值，**装门之前必须根据实际安装校准**。

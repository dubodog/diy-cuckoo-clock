# 单次布谷声音

将本目录`mp3`文件夹复制到TF卡根目录，得到`/mp3/0001.mp3`。文件包含一次完整双音节“布谷”，由固件控制次数。

原录音：Cuculus canorus，Vladimir Yu. Arkhipov（Arkhivov），2009-05-05。
来源：https://commons.wikimedia.org/wiki/File:Cuculus_canorus.ogg
许可：[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)。
改编：截取原录音约0.50–1.55秒，调节音量、淡入淡出并编码MP3。本项目改编文件也按CC BY-SA 3.0发布，原作者不表示认可本项目。

这是鸟类录音剪辑，不是实体时钟验收录音。128MB卡容量足够，格式及低价播放器兼容性需要实测。

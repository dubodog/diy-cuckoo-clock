# Anatomy 深度调研与项目使用决定

调研日期：2026-10-16。固定源码版本：`e9488296a44211c42701ff71705b7901470ec78f`。

## 结论

**可以使用，定位为机构与动作的可视化辅助工具；不能单靠它产出已经验证的实物装配教程。** 本项目优先选择轻量SVG/HTML。暂不引入WebGL、整机自由旋转3D或大量装饰零件；未全局安装技能，也未新增生产依赖。

这里的“适用”是根据源码和官方示例运行结果作出的工程判断，不是已完成布谷鸟钟模型、视频或实物装配的声明。

## 1. 它实际提供什么

已阅读官方README、SKILL.md、许可、最小表盘示例、截图脚本、浏览器启动辅助、CI配置及投影回归测试。

- 技能层：指导代理先建行为模型，再建零件、投影、遮挡、动画，最后截图和几何检查。
- 绘图库：`kit/iso-kit.mjs`提供投影和实体绘图；lathe/tube提供旋转体与管线；audit处理已建模几何的交叠、连接和绘制顺序。
- 输出层：独立SVG/HTML，也可接入React。它不是采购平台、CAD制造图生成器或固件开发包。
- 检查层：capture/drive借助Chrome生成截图和交互检查，lines检查线条末端。测试只针对被建模的内容，不能证明实物可插合、不会接反或电源足够。
- 可选3D仍在上游标为beta；需要更多几何和帧性能验证。

源码：[SKILL.md](https://github.com/wheresryan22/anatomy/blob/e9488296a44211c42701ff71705b7901470ec78f/SKILL.md)、[kit目录](https://github.com/wheresryan22/anatomy/tree/e9488296a44211c42701ff71705b7901470ec78f/kit)、[官方说明](https://skills.wheresryan.sh/anatomy)。

## 2. 与本项目的匹配程度

| 需求 | 判断 | 使用前提 |
|---|---|---|
| 双门同时打开、鸟后出先回 | 很适合 | 动画遵循固件阶段；不是三条各自无约束循环动画 |
| 夜间静音、整点次数 | 适合 | 同一时间规则驱动画面及读数；13点显示1次，不是13次 |
| 机身、转轴、单臂相对位置 | 有条件适合 | 按实际照片和测量建模；标明非实拍 |
| 门怎样固定在单臂上 | 暂不能直接给安装结论 | 先完成实际连接设计和试装；目前孔径/材料厚度没有足够证据 |
| 插头从哪里插入 | 可做放大动作辅助 | 必须先核对端面、线序、对应实际引脚 |
| 电容正负极、供电分线 | 图解能帮助理解 | 需要真实负极条和接线核查；美术审计无法发现接反 |
| 九岁孩子逐步跟做 | 必须改造默认风格 | 中文标注、线色、手拿位置、一次一个动作、完成检查 |
| 分步骤视频 | 可作为动画素材来源 | 另做动作编排、录制/渲染、语音字幕和实际跟做验收 |
| 成品是否真正可靠 | 不适用 | 仍要真实供电、限位、五轮动作和时段测试 |

## 3. 不能照搬的默认规则

上游鼓励“发明一种能解释概念的实物”，参考图主要提取质感，并偏好图内少文字。我们的目标是复现已经买到的零件，因此必须改变这些偏好：

1. **先实物，后建模**：蓝SG90、短单臂、实际三孔插头必须和用户零件对应；不可为画面好看换成虚构金属机构。
2. **允许明确标签**：D3、GND、正负极、插入方向及局部编号必须清晰；不隐藏在图下长段说明里。
3. **保留实际线色**：SG90黄/红/棕，杜邦蓝公公、黄母母、红公母；不能统一灰色导致混淆。
4. **每步只显示必要内容**：不以“至少40个零件”的视觉密度要求增加孩子认知负担。
5. **已知和未知分开**：尺寸未量、固定未试的部分标“待确认”，不能渲染成已经可照做的安装图。

这些改动是项目需求优先于工具审美规则的适配决定，不是对原技能验证结果的承诺。

## 4. 技术路线

推荐把资料分为三层：

- **事实层**：hardware/BOM.md、WIRING.md、实际尺寸记录和固件Config.h。事实变化先改这里。
- **行为层**：固件状态机与测试是当前依据。未来可视化读取导出的时间/角度配置，并用同一套典型场景核对；目前尚未建立自动导出，不声称已经共享代码。
- **展示层**：一个小步骤一张交互卡；可暂停、重播、切换“操作前/后”和查看实物近照。成人检查与孩子操作清楚区分。

首个定制图应只解释“两个门同时开 → 鸟出来 → 布谷 → 鸟回去 → 两门关”，标记为原理示意。待实际连接方案确认后再制作单臂固定、舵机平台和电源接线课。

若需要视频，按动作时间轴导出连续帧或录屏，再合成配音字幕。不要把网页/PDF截图轮播当成安装动作演示。WebGL的火焰、液体等功能对本钟没有必要；物理3D打印也不是使用该技能的前提。

## 5. 环境、费用与许可

上游技能声明Node.js 20.10+及Chrome/Chromium；基础构建使用Node内置模块，不需要API密钥。`npx skills`安装器的Node要求与绘图库运行要求不同，不能混为一谈。当前本机Node 24.14.0可运行示例。

源码MIT许可，复制kit或技能时需保留Copyright (c) 2026 Ryan及MIT许可。免费开源不意味着生成工作免费：代理推理、动画制作、录制与实物验证仍花时间和可能的服务费用。它本身不增加布谷鸟钟的材料费。

仓库源码与技能不等于展示站所有第三方素材的无限授权；本次未搬运网站图片作为我们的成品图。鸟叫另按CC BY-SA 3.0处理。

以后确定采用时，优先固定版本安装在本项目`.agents/skills/anatomy/`，保留上游许可并记录版本；不要改变全局Codex权限或执行网页建议的宽松权限配置。安装不是本次研究结论生效的前提。

## 6. 本次验证与边界

在独立临时目录读取固定版本源码，检查后运行最小dial-indicator示例构建与手机宽度截图，并执行投影回归测试；结果见[验证记录](../VERIFICATION.md)。

这是对“本机能运行其基础构建/检查”的验证。未跑上游全部React/WebGL/3D测试，未对整套上游脚本完成安全审计，未实现本钟的定制Anatomy模型，未将图形几何审计当作实体认证。

## 7. 后续可直接使用的制作要求

> 以项目已核实的SG90、短单臂和接线为依据，制作一个可暂停的动作小课。保持实物方向，先列缺失的尺寸证据，再绘制已确定内容。画面使用中文标签和实际线色；数字与动作来自同一行为模型。展示拿哪个零件、对准哪里、怎样运动、完成后检查什么。双门同时动作，鸟后出先回。未实测的连接不得声称可直接装配，图形/动画明确标为示意。先交付一个能被第一次接触的人跟做的小步骤，再扩展完整课程。

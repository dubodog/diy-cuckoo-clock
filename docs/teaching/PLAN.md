# 教学返工计划

## 当前事实

旧版有PDF和24段配音视频，但用户无法据此装配。V4已经做了材料识别、端子动作动画、实际杜邦线和舵机单臂识别；完整机械和电路安装仍未完成。旧资料不作为当前安装依据。

## 每课必须包含

1. 本课只做一件事；摆出这次真正要用的零件。
2. 实物照片对应同一观看方向，标出拿哪里、对哪里。
3. 展示从未接到接好的连续动作；关键插入方向放大，允许暂停和重播。
4. 一次只接一根线；文字说“把蓝线的针插进D3”，不只说“接信号”。
5. 给出完成近照和一个可检查结果；错误姿态也展示。
6. 成人操作明确标出。电源和电容极性由成人复核。

## 课程拆分顺序

认识实际单臂和转轴 → 单舵机空载定位 → 测量并制作可靠固定支架 → 单门试装 → 第二门镜像同时动作 → 鸟架进出 → 电源母线与电容 → 播放器及喇叭 → RTC与校时 → 整机验收。

课程顺序允许因实物连接调整；尚未确定的安装方法不先生成“操作视频”。

## Anatomy参与的位置

用于已确认连接的爆炸图、双门状态与鸟的顺序、动作前后对照。实际接线用真实零件特写和明确引脚。保留中文标签、彩色线和指向标记，不服从“不加标注”的装饰性限制。

## 完成判据

- 第一次看到教程的人能指出要拿哪个实际零件，并完成该步。
- 两门同时启动且不互撞，鸟不撞门，连续至少五轮。
- 核验08/12/13/20/21点以及断电后校时，实际次数正确。
- MP4包含动作变化、对应字幕、暂停点；不是PDF翻页朗读。
- 数字模拟、AI效果图和真实装配照片分别标注，不能相互替代验收。

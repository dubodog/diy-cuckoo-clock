# 接线约定（设计表，非逐步安装说明）

以下表与当前固件一致。实际板子和插头的朝向尚需照片核对；先断电接线。儿童装配需成人核对极性和供电。

| UNO | 目标 |
|---|---|
| D3 | 左门SG90黄色信号线 |
| D5 | 右门SG90黄色信号线 |
| D6 | 鸟SG90黄色信号线 |
| D7 | DFPlayer BUSY |
| D10（软件串口RX） | DFPlayer TX |
| D11（软件串口TX） | 串联1kΩ后到DFPlayer RX |
| A4 | DS3231 SDA |
| A5 | DS3231 SCL |
| 5V | DS3231 VCC |
| GND | 公共GND、DS3231 GND |

外部稳压5V正极分给三舵机红线和播放器VCC；外部GND分给三舵机棕线、播放器GND，并接UNO GND。UNO由自己的USB供电，**外部+5V不再接UNO 5V插孔**。三只舵机不从UNO 5V插孔取电。

两个PCT218分别做+5V、GND汇流，每个内部全部导通。不能把正负极放入同一个共通端子。电容跨接外部+5V与GND，负极条一侧接GND。电容不是串在电线中。

喇叭两根线分别到SPK1、SPK2，不能把其中一根当公共地。DFPlayer具体引脚必须核对板上印字。

SG90插头侧面露出金属的小窗口不是插孔；从插头端面的孔插入。按原装黄/红/棕线追踪孔位，不用照片的“左边/右边”猜极性。

尚未确定：成品杜邦线与PCT的可靠过渡。不要把塑料接头硬塞入PCT，也不把未检查的插针夹持当作可靠连接。最终教程必须给出实际线束接法和拉拽检查。
